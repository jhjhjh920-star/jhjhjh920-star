# 이진하
### 모바일 카메라 ISP NR·EE 튜닝 엔지니어

2020년부터 모바일 카메라의 노이즈 저감과 윤곽 강조를 조정해 왔습니다. 고객이 제기한 화질 이슈의 촬영 조건을 재현하고, 실촬영과 RAW 시뮬레이션을 비교해 원인 범위를 좁힙니다.

반복되는 촬영·검증 작업에서 필요한 기능을 직접 정의하고 업무 지원 도구를 제작했습니다. 이 공간에 도구의 목적, 구현 과정과 확인 결과를 정리합니다.

## 화질 튜닝 경험

- **NR·EE 조정** — 노이즈 억제, 질감·디테일 보존, 선명도와 경계 부작용의 균형 검토
- **고객 화질 이슈 분석** — 조도·Gain·촬영 모드와 적용 설정을 확인하고 이슈 재현
- **실촬영과 RAW 시뮬레이션 비교** — 비교 결과에 따라 원인 범위를 좁히고 추가 확인 조건 정리
- **영상 품질 확인** — 프레임 간 노이즈 변동, 움직임 잔상, 설정을 공유하는 모드·해상도에 미치는 영향 확인

**사용 경험:** Samsung System LSI Picasso · Qualcomm Chromatix 7 · RAW 시뮬레이션 · ADB

## 업무 지원 도구

| 도구 | 해결하려는 작업 | 주요 기능 |
| --- | --- | --- |
| **ISP Automation Tool** | 단말 조작부터 촬영 자료 수집까지 반복되는 작업 정리 | ADB 기반 단말 제어·미러링, 촬영 조건 변경, 촬영 전후 파일 목록 비교와 RAW·JPG 수집 |
| **RAW Scope** | RAW 입력 조건을 반복해서 설정하고 영상을 비교하는 작업 개선 | 해상도·저장 형식 후보 탐색, RAW 미리보기, 조정 전후 비교, ROI 히스토그램·통계 확인 |

RAW Scope의 자동 탐색 결과는 입력 조건의 **후보**이며, 영역 통계는 **8비트 표시 영상 기준**입니다.

### 제작 과정에서 맡은 역할

화질 튜닝 실무에서 필요한 기능과 작업 순서를 정의하고, 화면 구성과 동작 확인을 담당했습니다. 구현과 개선 과정에는 **AI 코딩 지원**을 활용했습니다.

두 도구의 소스와 실행 자료는 공개 준비 중입니다. 현재 사용하는 도구와 소스 코드를 대조한 후, 실행 방법·검증 결과·알려진 제약을 각 저장소에 정리할 예정입니다.
